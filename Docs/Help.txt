@@ PicoMenu 1.9 help
This guide outlines how some of
the more complex functions work.
Copying, moving and erasing
files are self explanatory.

N-Next page  P-Previous page
D-Diagnostics  X-Exit

@@ The NMI button
The NMI button (top right of the
Picoface) has three functions:

1) A short press takes you
   into the NMI menu.
2) Holding it for one second
   resets the Spectrum.
3) A double press takes a
   quick screen grab and puts
   it in the /Screen Grabs
   folder.

@@ Setting up the SD card
On first start of PicoMenu you
can choose D - Set up SD card
(the card needs to be exFAT or
FAT32). This puts the folders on
the card that some functions
need. For instance it makes a
/Favourites folder, which you
can use to add favourite games
to quickly. It also makes a
sample Instructions.txt, which
you can use to add the game
information shown on the Game
View screen.

@@ Setting up the SD card (2)
You can also make the folders
yourself. They need to be in the
root of the SD card and named:

/Favourites
/Save Games
/Screen Grabs
/Scraper
/Game Notes
/Poke List

@@ Convert .tap/.tzx to .z80
.tap/.tzx files that use speed
or turbo loaders, or similar
techniques, will not always load
on the Picoface. PicoMenu can
convert a .tap/.tzx file into a
.z80.

Enter the NMI menu and press
B - Browse Games. Press V - View
and choose a .tap/.tzx file. The
tape information comes after the
game information, so the last
two pages of the View screen say
whether PicoMenu can load the
.tap/.tzx, then give the tape
details.

@@ Convert .tap/.tzx (2)
Press C to convert the .tap/.tzx
file to a .z80. The .z80 is
written in the same folder. Then
choose:

A Auto: on a 128K Spectrum a
  128K .z80, and if that
  fails a 48K one
4 a 48K .z80
1 a 128K .z80

A progress bar and the time
taken are shown in the bottom
left corner. You can press BREAK
at any time to stop. When it has
finished it tells you if it has
saved or failed.

@@ Convert: loading screens
The conversion also takes a
screen grab (.scr) of the
loading screen by itself and
puts it in the
/Scraper/Screen Grabs folder.
The top of the screen then says
"Loading screen saved". If you
press BREAK to stop, this file
is deleted.

You can also take screen grabs
by hand by pressing S. These are
kept even if you press BREAK, so
you can grab a loading screen
without going through the whole
conversion.

@@ Convert: the ROMs
To convert you need 48.rom, and
128.rom (or 128-0.rom and
128-1.rom), in the root of the
SD card or the flash.

48.rom   16384 bytes
128.rom  32768 bytes
128-0.rom, 128-1.rom
         16384 bytes each

@@ Diagnostic and other ROMs
For convenience you can press T
on the NMI menu to go straight
to the diagnostic ROMs.
testrom.rom and/or DiagROM.rom
must be in the root of the
flash.

You can also change the ROM with
C - Change ROM. If you run a ROM
(from the Test ROM or Change ROM
screen) and want to go back to
the internal ROM, press the NMI
button, choose C - Change ROM
and then press 1 - Internal Rom.

@@ Change ROM: Writable
W-Writable [ ] on the Change ROM
screen makes the ROM area above
address 63 writable, for
programs that patch it.

@@ Quick save
Quick save saves a snapshot
straight to the /Save Games
folder. If there is already a
file for that game, it asks if
you want to overwrite it. If you
say no, it saves under the next
free number (<game> Save Game 2,
3 and so on).

@@ Hidden folders
You can use Windows to hide
folders on the SD card. In
B - Browse Games, press L - All
to show the hidden folders.
L-All is highlighted in blue
while they are shown, and you
can then move, erase, copy and
so on the hidden folders and
their files. Hiding little used
folders keeps the screen clean.

@@ Search function
You can search in
B - Browse Games with F - Find.
You can search inside a folder,
or from higher up (these
searches take longer). You can
move, copy and so on the files
you find. Press F again to clear
the search.

@@ File types
.sna  48K and 128K snapshots
.z80  all versions, 48K and
      128K, packed or not. The
      sound chip is restored
      (.sna files have none).
.szx  48K, 128K and +2 (from
      Fuse, Spectaculator).
      Packed or not. Not +2A/+3.
.tap/ tape images
.tzx
.pok  poke lists
.rom  ROM files
.scr  screen grabs
      .pok, .rom and .scr are
      listed to copy, rename
      and so on, not loaded.

@@ File types: limits
.tap/.tzx: turbo and custom
loaders that time the signal
themselves do not load directly
(see Convert .tap/.tzx to .z80),
nor games that load parts
without the ROM loader.

@@ Edit game info and notes
On the V - View screen you can
edit the game's details and make
your own notes. Press M, then:

H  the software house
Y  the release year
C  the controls (512 letters)
I  the instructions (2048
   letters)
N  your own notes
R  take back all you typed in

@@ Edit info: where kept
What you type in does not change
the Instructions.txt file. It is
kept in the /Game Notes folder:
the details as
<game name>.info.txt and your
notes as <game name>.txt.

What you type in is shown
instead of what Instructions.txt
says, without changing or
deleting it. If you delete what
you typed in, the information
comes from Instructions.txt
again (if it has any).

@@ Pokes
Poke lists are kept in
/Poke List as .pok files. When
you load a game, PicoMenu looks
for a .pok file with exactly the
same name. For example
Exolon.z80, .sna, .szx, .tap or
.tzx needs a file called
Exolon.pok.

If it finds one, its pokes are
shown in the poke list
(P - Poke, then L). A poke that
needs a number asks for it
(0-255).

@@ SD card on a PC
It is strongly recommended that
you only use a PC to view the SD
card through the Pico while the
Spectrum is off.

With the Spectrum off, plug the
Pico's USB cable into a PC. The
SD card appears as a USB drive
and you can add, remove and edit
folders and files.

@@ SD card on a PC (2)
If you hide a folder in Windows
it is hidden in PicoMenu too.
You can show hidden folders in
PicoMenu with L - All (see
Hidden folders).

Before unplugging, use Safely
Remove (eject) on the PC, to
avoid damaging the SD card.

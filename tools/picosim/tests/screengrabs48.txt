# Screen grab categories. V shows a game's pictures category by category, in the order of
# /Scraper/Screen Grabs/order (tests/grab-order.txt: Ending Screen, Standard Screen Number,
# Loading Screen, From File; Menu Screen is a comment and Game Screen left out, so neither is
# shown), and by number in each; one left in the old /Screen Grabs comes after the Standard ones.
# From File is the snapshot's own screen. D deletes the one shown, the first, so they go in that
# order (D does nothing on the file's own picture). Then G asks the category and saves in
# /Scraper/Screen Grabs, the lowest number free; a double press saves as Standard Screen Number.

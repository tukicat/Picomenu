# Level loaders (multi-load, stage B): a game with its own loader in RAM, starting as the ROM's
# LD-BYTES does (as Out Run's Speedlock releases load their stages with a copy of it), gets its
# blocks from the tape trap, with no poke: the Pico finds it and makes it jump to the trap's hook
# at 0x0562.
# levelloader.z80 waits until 0x9000 is set, then loads 4 bytes to 30000 with its loader and
# puts 4 at 30010. levelloader.tap starts the same code with LOAD ""CODE, and it loads the
# tape's last block (1 2 3 4) at once. Both are made by tests/make_levelloader.py (run.sh runs it).
flash /48.rom {ROM48}
sd /Picomenu.ini {HERE}/levelloader-off.ini
sd /Games/levelloader.z80 {OUT}/levelloader.z80
sd /Games/levelloader.tap {OUT}/levelloader.tap
boot
# level_loaders = off: nothing is changed, and the game waits for a real tape
nmi
wait 30
key b
wait 50
key 1
wait 50
expect 2-levelloader
key 2
wait 100
nmi
wait 30
key b
wait 50
key t
wait 20
key 1
wait 100
poke 0x9000 1
wait 200
expectmem 30010 0

# High score tables (Pico W, T on A - Autosave, or the hotkey T): found from a name or a score in
# the game's table, saved to /High Scores/<game>.txt and .bin, saved again each time the menu is
# opened, and put back into the game when it is loaded (a snapshot: before it starts; a tape: when
# the menu is first opened). R puts it back, C forgets it.
sd /48.rom {ROM48}
sd /Picomenu.ini {HERE}/hotkeys.ini
sd /Games/Alpha.z80 {TAPES}/Green_Beret_1986ImagineSpeedLock_2-48.z80
